Raid rules

Raid on the weekend, rest during the week

Hard raids only run on the weekend and start in week 2 of the wipe, so you can build up first and go to work on Monday without losing your base overnight. Only doors can be blown, with C4, and build restrictions stop mega-bases, so raiding stays fair for attackers and defenders.

The wipe levels up every week

All events are wipe-based. Week 1 is for building up in peace, then raids and helicopters open up and the loot gets better every week, so a wipe never gets boring.
